# Innovelous

> A next-generation digital agency website — engineering high-performance web apps, mobile apps, and custom software pipelines.

Built with [Next.js](https://nextjs.org/), [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Tailwind CSS](https://tailwindcss.com/), and [Three.js](https://threejs.org/).

---

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
